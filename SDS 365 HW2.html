Image Compression Function

image_compress <- function(x, k) {
  V <- t(x) %*% x
  eigen_decomp <- eigen(V)
  U <- eigen_decomp$vectors
  Z <- x %*% U
  U_k <- U[, 1:k, drop = FALSE]
  Z_k <- Z[, 1:k, drop = FALSE]
  x_approx <- Z_k %*% t(U_k)
  error <- norm(x - x_approx, type = "F")
   return(list(
    approximation = x_approx,
    error = error ))
}

# set up plots
par(mfrow = c(3, 4))
# original image
image(t(x), col = gray.colors(256), axes = FALSE, main = "Original")
# approximations for k = 1 through 10
for (k in 1:10) {
  result <- image_compress(x, k)
  image(t(result$approximation),
        col = gray.colors(256),
        axes = FALSE,
        main = paste("k =", k)) }
# calculate error for each k
errors <- numeric(ncol(x))

for (k in 1:ncol(x)) {
  result <- image_compress(x, k)
  errors[k] <- result$error }
# plot approximation error
plot(1:ncol(x), errors, type = "l", xlab = "k", ylab = "Approximation Error", main = "Approximation Error vs. k")
# calculate eigenvectors and PC scores
V <- t(x) %*% x
eigen_decomp <- eigen(V)
U <- eigen_decomp$vectors
Z <- x %*% U
# get the first eigenvector and first PC score
u1 <- U[, 1]
z1 <- Z[, 1]
# two plots next to each other
par(mfrow = c(1, 2))

plot(u1,type = "l", xlab = "Column", ylab = "Eigenvector Value", main = "First Eigenvector")
plot(z1, type = "l", xlab = "Row", ylab = "PC Score", main = "First PC Score")

The first eigenvector is close to zero for most columns, with one large spike near column 78. This indicates that the first principal component is mainly influenced by variation in that column. The first PC scores show how strongly each row of the image aligns with the first principal component. The scores stay around a similar level across the rows, with repeated peaks and dips.

I think k = 5 provides a sufficiently good approximation of Image 1. By k = 5, the main features of the original image are already visible, and increasing k only produces small visual improvements.
